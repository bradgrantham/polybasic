# Recovered programs

Applesoft programs recovered from Brad Grantham's own Apple II disks (see
`../../../apple2-disks-unpacked`), copied here unchanged so that the suite
runs real programs as well as purpose-written tests.  Each has scripted input
in `NAME.in` and expected output in `NAME.out`.

Only programs written by the repository's owner are copied.  The commercial
programs in the collection are checked in place by `tools/corpus.py`.

`pictures/` holds graphics programs from the same disks.  Each also has
`NAME.png`, the screen as the program left it, written with `--png`.
